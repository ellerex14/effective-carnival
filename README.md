# Emjey Restaurant Website

A responsive, three-page restaurant website built with HTML and CSS.

## Project structure

```text
my-website/
├── index.html
├── about.html
├── gallery.html
├── css/
│   └── style.css
├── images/
└── README.md
```

## How to run

1. Extract the project folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the Home, Our Story, and Menu & Gallery pages.

## Customize

- Edit the restaurant name, descriptions, menu items, and prices in the HTML files.
- Update the address, opening hours, and contact details with the restaurant's actual information.
- The sample food and restaurant photos currently load from Unsplash, so an internet connection is needed to display them.
- To use your own photos, place them in the `images/` folder and replace the photo URLs in the HTML with local paths such as `images/your-photo.jpg`.
- Change colors, fonts, spacing, and responsive layouts in `css/style.css`.

## Notes

Menu items, prices, contact information, and business hours are sample details for a website presentation. Confirm and replace them before publishing.
